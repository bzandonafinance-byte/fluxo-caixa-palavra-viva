# Fluxo de Caixa - Colégio Palavra Viva

Dashboard de fluxo de caixa do colégio, com Visão Geral, Aging AP, Aging AR e
relatório de fluxo de pagamento com filtro por período (Dia / Semana / Mês).

## Arquivos

- `Dashboard_Fluxo de caixa.html` — dashboard pronto para abrir direto no
  navegador (Chrome, Edge, etc.), sem precisar de instalação. Todos os dados
  ficam embutidos no próprio arquivo.

A planilha fonte dos dados (`Fluxo de Caixa_2026.xlsx`) fica só na pasta
local do Financeiro — não é versionada neste repositório.

## Como atualizar o dashboard

O dashboard é uma "foto" dos dados da planilha no momento em que foi gerado.
Para atualizar os números, é preciso gerar uma nova versão do HTML a partir da
planilha mais recente — fale com o Bruno (Financeiro) para isso.

## Aviso

Este repositório contém dados financeiros internos do colégio embutidos no
dashboard (saldos, fornecedores, valores de pagamento). Repositório privado —
não compartilhar fora da equipe.
